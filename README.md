# 线边物料配送 · 可视化与成本测算软件（参赛作品演示端）

安徽省"人工智能+物流"方案设计赛配套软件（MIT 开源）。与数据汇报一起呈现：
**四组对照实验的实测可视化 + 补货参数即时测算（解析公式 × 迷你离散事件仿真双引擎）+ 成本口径联动 + SS_t 闭环导出**。

## 快速启动（答辩日）

1. `pip install -r requirements.txt`（Python 3.11+，仅需 fastapi/uvicorn/pandas/numpy；全功能离线）
2. 数据随仓库：`data/`（四组主实验 + 压力组 5.1 的 FlexSim 原始日志/报表、车间坐标表、模型平面图）
3. **双击 `start.bat`**（或 `python run.py`）
   - 首次启动自动重建缓存（读 5 组日志约 30~60s），之后秒开
   - 端口 `8765`，被占用自动 +8 递增，并自动打开浏览器
4. 全部功能**离线可用**：ECharts 已本地化（`static/vendor/`），无任何外链

```
python -m app.precompute --force   # 手动重建缓存 + 平面图转SVG
python -m app.sim.calibrate --force # 重跑仿真标定（组3 三种子）
python tools/verify_data.py         # 演示前一键核对：原始文件 vs 缓存 vs v3口径
python tools/make_dist.py           # 打免安装绿包 → dist/线边物流演示端/（整文件夹拷U盘，271MB）
```

## 口径与算法说明（评委答疑用）

- **KPI 全部原始文件计算**：库存均值=summaryreport `stats_contentavg` 10 库合计；行驶段数=日志 `BeginTask: Travel` 计数（报表"任务次数"是另一口径，两者同列于明细表）
- **压力工况组5.1**（看板"压力工况验证"区 + 回放页"压力5.1"页签）：与组3 唯一差异 = 工位消耗表达式均值/σ 同除 1.495（实为 ×1.15 与 ×1.3 两次改动叠加），实测消耗节奏 ≈×1.5。结果：产出 1951 台（满负荷、未停线，台前操作手队列吸收分钟级断料），但**触零 972→2193 库·分钟（×2.25）、任一库空库 781→1292 分钟、段数 1118→1627**——静态安全边际被吃穿的直接证据。距离/标定表只用主四组（压力组腿时长剔除，防车队拥堵污染）。**该组数据按文件存在与否自动装配**：删除 `lab5.1/summaryreport5.1/statereport5.1` 后重跑预计算即回到纯四组形态
- **库存曲线重建**：OnEntry +1 / OnExit −1（Engine 家族重复记录剔除），常数偏移 c0 标定至报表均值并整数吸附，min/max 与报表对照 ≤±1，曲线含 ±1 件起点不确定度（界面 tooltip 已声明）
- **成本模型**：C = c_d×段数 + h×平均库存×120h + 人工常数 + c_stop×缺料分钟；预设 A 相对系数（1.0/0.5/1.0/2.0）出相对结论，预设 B 占位绝对值仅示量级
- **解析公式可信度回算**：Ī(定时)=Q−λf/2→54.4(实测54.0)；Ī(阈值)=(SS+Q)/2→20.0(实测20.65)；Ī(拉动)→5.98(实测5.95)
- **迷你仿真标定**：组3 参数 ×3 种子，等效轮询 1800s / 单车容量 4 箱（标定旋钮，等效≠FlexSim 原值，已在页面声明），库存 +5.6% / 段数 −0.6% / 产出 +1.1%，≤10% 验收通过
- **AI 模块现状**：本版软件不含在线 AI；XGBoost 对最优 SS_t 回归 R²=0.020（诚实呈现），闭环页仅讲系统故事

## 目录结构

```

data/                     FlexSim 原始日志/报表 + 坐标表 + 平面图（随仓库分发，MIT）
config/                   settings.json 路径端口 · cost_basis.json 当前口径(PUT持久化) · presets.json
app/ingest/               报表/日志/坐标解析
app/sim/                  engine.py 迷你DES · analytic.py 闭式公式 · calibrate.py 标定
app/api/                  dashboard · replay · estimate · cost · export · misc
static/                   前端（hash路由5页，ECharts本地vendor，全离线）
cache/                    预计算产物（replay_g*.json ≈ 1MB/组, kpi_actuals, calibration, distances, layout）
tools/verify_data.py      演示日核对
```

## 故障速查

- 页面顶部红条"数据路径缺失"：改 `config/settings.json` 的 `data_dir` 后刷新
- 缓存缺失/过期：`python -m app.precompute --force`
- 端口被占：无需处理，run.py 自动换端口（看命令行输出的 URL）
- 图表空白：F12 看是否被安全软件拦了本地脚本；本软件不访问外网
