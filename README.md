# FlexSim 线边物料配送 · 数字孪生可视化与成本测算

**FlexSim Line-Side Material Delivery Simulation & Cost Analytics for Automotive Final Assembly**
—— 汽车总装车间 AGV 配送四组对照实验的参赛作品演示端：动态安全库存（Dynamic Safety Stock, SS_t）vs 静态参数、离线数字孪生回放、解析公式 × 迷你离散事件仿真双引擎测算。

安徽省"人工智能+物流"方案设计赛配套软件（MIT 开源）。与数据汇报一起呈现：
**四组对照实验的实测可视化 + 补货参数即时测算（解析公式 × 迷你离散事件仿真双引擎）+ 成本口径联动 + SS_t 闭环导出**。

## 项目介绍

### 1 · 研究背景与问题提出

汽车总装车间的线边物料配送由一条因果链驱动：**工位消耗 → 线边库水位下降 → 触发补货 → AGV 从超市取货送达**。这条链的运行质量由三个补货参数决定——安全库存 **SS**（何时补）、补货批量 **Q**（补多少）、检查周期 **f**（多久看一次）。工程惯例是这三个参数在爬坡期一次性定死、长期不变，其隐含假设是需求过程平稳。

真实产线并不平稳。本项目的仿真场景里，每 8 小时班次末段 2 小时出现需求均值 ×1.5 的规律性突变（120h 内共 15 个突变窗）。静态参数被迫陷入两难：**为峰值配置冗余，则平峰期库存与运输浪费；为平峰配置，则峰值期暴露缺料风险**。

> **研究问题**：把补货参数从"定死的常数"变为"随工况调整的变量"，能为线边配送带来什么？其代价与收益如何在库存、运输、缺料风险三者之间交换？

### 2 · 实验设计：四组受控对照

以 FlexSim 建立同一产线骨架——**10 个装配工位 × 10 个线边暂存库 × 2 台 AGV**（速度 2 m/s，装卸 N(30,3) s/箱），需求过程、路段时长、统计窗（预热 2h + 全程 118h，仿真总长 120h）完全一致，**唯一变量是补货策略**：

| 组 | 策略 | 参数 | 设计意图 |
|---|---|---|---|
| 组1 | 逐件拉动 | 缺口即补 1 件，库容 6 | 库存下界基线（运输上限） |
| 组2 | 定时补满 | 每 f=3600s 将库位补满至 6 | 批量化的作用 |
| 组3 | 阈值最小补 | 固定 SS=1、补至 3 件、车容 3 | 阈值触发 + 最小批量 |
| 组4 | **动态安全库存** | **SS_t 按小时查表（121 行）**，其余同组3 | 参数变活 |

归因链条：组1→组2 度量**批量化**贡献（−22%）；组2→组3 度量**阈值最小化**（−51.6%，此步批量与车容同变，**不干净**，看板已明确标注）；**组3→组4 是唯一干净的单变量对照（仅 SS 静→动）**，全项目的结论只建立在这一跳上。

### 3 · 主结果

所有数字由 15 万行/组的原始事件日志重算（口径见 §6），与 FlexSim 报表交叉验证：

| 指标 | 组1 | 组2 | 组3 | 组4 |
|---|---|---|---|---|
| 线边库存均值（件） | 59.474 | 54.002 | **20.650** | 23.250 |
| AGV 行驶段数 | 2581 | 1296 | **1118** | 1299 |
| 产出（台） | 1291 | 1291 | 1291 | 1291 |
| 缺料停线（分钟） | 0 | 0 | 0 | 0 |
| **线边触零时长**（库·分钟） | 0 | 0 | **972** | **120** |

**组4 vs 组3**：库存 +12.6%、段数 +16.2%——这是"120h 零缺料"硬约束下动态策略付出的**过配代价**；而买到的东西是**触零暴露从 972 降到 120 库·分钟（−87%）**，即空库风险窗口的数量级压缩。

> **结论的诚实表述**：动态参数不是"全面更优"，而是**用可度量的库存/运输增量成本，交换缺料风险暴露的大幅下降**。这笔交换是否划算，交给成本模型（§5）在给定单价下判定。

### 4 · 外部效度：压力工况检验（组5.1）

主四组保证**内部效度**（单变量干净对照），组5.1 检验结论在现实扰动下是否仍然成立：在组3 基础上**仅**将工位消耗过程整体提速 ≈×1.5（其余参数与组3 逐项相同）。

结果：产出 1951 台（满负荷）且**缺料停线仍为 0**——台前操作手队列吸收了分钟级断料，这本身就是值得汇报的真实机制；但**触零升至 2193 库·分钟（组3 的 ×2.25）、任一库空库时长 781→1292 分钟、行驶段数 +46%**。静态 SS=1 的安全边际被需求增幅吃穿，**动态 SS_t 的价值论证在压力下反而增强**（组4 的 SS_t 峰值时段自动抬高一档，覆盖逻辑见测算页）。

### 5 · 成本模型与口径纪律

四段式全成本：**C = c_d×行驶段数 + h×平均库存×120h + c_labor×固定人工 + c_stop×缺料分钟**。双预设口径：
- **预设 A（相对系数）**：1.0 / 0.5 / 1.0 / 2.0，只出相对结论，不涉金额；
- **预设 B（行业占位绝对值）**：80 元/段、0.35 元/件·h、5000 元/缺料分钟等，**仅示意量级**，页面常驻免责声明——绝对金额须经企业实价确认后方可引用。

两条口径纪律：**人工是班组常数，本项目不声称省人工**；成本单价全字段界面可编辑并持久化。

### 6 · 方法学：数据管线与双引擎校验

- **库存曲线重建**：事件流 OnEntry +1 / OnExit −1 逐笔积分（Engine 家族重复记录剔除），常数偏移 c0 以时间加权均值对齐报表、向整数吸附；min/max 与报表对照 ≤±1 件，起点含 ±1 件不确定度（界面 tooltip 如实声明）。
- **解析引擎**（毫秒级）：闭式公式回算实测——Ī(定时)=Q−λf/2 → 54.4（实测 54.0）；Ī(阈值)=(SS+Q)/2 → 20.0（实测 20.65）；Ī(拉动) → 5.98（实测 5.95）。需求率 λ=1.125 件/h/库 由突变窗占空比精确推导。
- **仿真引擎**：Python 迷你离散事件模型复刻组3 逻辑（heapq 事件堆 + 日志标定路段时长表），组3 参数 ×3 种子标定：库存 +5.6% / 段数 −0.6% / 产出 +1.1%，≤10% 验收通过（等效参数映射已在页面声明）。
- **AI 的诚实呈现**：对"最优 SS_t 查表"做 XGBoost 回归，样本外 **R²=0.020**——在本场景的样本量与平稳性下，仿真寻表优于端到端学习，我们不粉饰这个数字；当前版本软件不含在线 AI。
- **闭环通道**：测算得到的 SS_t 曲线一键导出 121 行 `hour,value` CSV，FlexSim `importtable` 直接灌回复跑——参数管线双向打开。

### 7 · 软件形态与可复现性

FastAPI + 本地化 ECharts（零外链，断网可用），五页：四组对比看板 / 120h 数字孪生回放（热力 + AGV 动点 + 触零红圈 + 变速播放）/ 参数即时测算（双引擎并排）/ 成本口径编辑 / SS_t 闭环导出。源码 `python run.py` 即起；`python tools/make_dist.py` 产出 271MB 免安装绿包（数据与预计算缓存随包）。**全部原始数据（17 文件 89MB）随仓库分发，本文每一个数字都可用 `python tools/verify_data.py` 一键复算**。

### 8 · 局限与后续工作

1. 场景为单一产线 120h、需求突变规律固定（8h 周期），SS_t 表按此寻优，跨工况迁移需重跑闭环；
2. 动态参数的收益以"零缺料"硬约束为前提，若企业可容忍短暂触零，最优 SS_t 会整体下移；
3. XGBoost 负结果表明学习型策略需更大规模/更多工况样本才可能超过寻表法，列入后续工作；
4. 成本绝对值依赖占位单价，正式引用前需企业参数确认（预设 B 已常驻声明）。

## 口径与算法说明（评委答疑用）

- **KPI 全部原始文件计算**：库存均值=summaryreport `stats_contentavg` 10 库合计；行驶段数=日志 `BeginTask: Travel` 计数（报表"任务次数"是另一口径，两者同列于明细表）
- **压力工况组5.1**（看板"压力工况验证"区 + 回放页"压力5.1"页签）：与组3 唯一差异 = 工位消耗表达式均值/σ 同除 1.495（实为 ×1.15 与 ×1.3 两次改动叠加），实测消耗节奏 ≈×1.5。结果：产出 1951 台（满负荷、未停线，台前操作手队列吸收分钟级断料），但**触零 972→2193 库·分钟（×2.25）、任一库空库 781→1292 分钟、段数 1118→1627**——静态安全边际被吃穿的直接证据。距离/标定表只用主四组（压力组腿时长剔除，防车队拥堵污染）。**该组数据按文件存在与否自动装配**：删除 `lab5.1/summaryreport5.1/statereport5.1` 后重跑预计算即回到纯四组形态
- **库存曲线重建**：OnEntry +1 / OnExit −1（Engine 家族重复记录剔除），常数偏移 c0 标定至报表均值并整数吸附，min/max 与报表对照 ≤±1，曲线含 ±1 件起点不确定度（界面 tooltip 已声明）
- **成本模型**：C = c_d×段数 + h×平均库存×120h + 人工常数 + c_stop×缺料分钟；预设 A 相对系数（1.0/0.5/1.0/2.0）出相对结论，预设 B 占位绝对值仅示量级
- **解析公式可信度回算**：Ī(定时)=Q−λf/2→54.4(实测54.0)；Ī(阈值)=(SS+Q)/2→20.0(实测20.65)；Ī(拉动)→5.98(实测5.95)
- **迷你仿真标定**：组3 参数 ×3 种子，等效轮询 1800s / 单车容量 4 箱（标定旋钮，等效≠FlexSim 原值，已在页面声明），库存 +5.6% / 段数 −0.6% / 产出 +1.1%，≤10% 验收通过
- **AI 模块现状**：本版软件不含在线 AI；XGBoost 对最优 SS_t 回归 R²=0.020（诚实呈现），闭环页仅讲系统故事
